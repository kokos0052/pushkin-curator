# UX: Мой куратор — 6 экранов

Mobile-first. Один главный action на экран. Тон: тёплый куратор, без «ИИ-помощник».

## Wireflow

```
Landing → Quiz (×4) → Generating → Route Overview → Stop Card (×N) → Finish / Share
                              ↘ Ask Curator (sheet)
```

## Копирайт

| Экран | Заголовок / ключевой текст | CTA |
|---|---|---|
| Landing | **Мой куратор** / «Маршрут под настроение, а не по каталогу» | Собрать маршрут |
| Quiz 1 | Сколько у тебя времени? | 30 / 60 / 90 мин |
| Quiz 2 | Какое настроение сегодня? | Спокойствие / Драма / Открытие |
| Quiz 3 | Что хочется увидеть? | Античность / Ренессанс / Импрессионизм / XX век / Скульптура |
| Quiz 4 | С кем идёшь? | Один / Пара / С детьми |
| Generating | Собираем маршрут | — (статус-строки) |
| Overview | Название + тема маршрута | Начать |
| Stop | История + «Почему тебе» | Спросить куратора / Дальше |
| Finish | Открытка маршрута | Поделиться / Собрать другой |

## Принципы

1. Крупные тап-зоны, минимум ввода текста (кроме Ask).
2. Тексты 2–3 предложения — читаются в очереди.
3. Собранный маршрут лежит в `localStorage` и в `?route=` для share.
4. Если YandexGPT недоступен — fallback без падения демо (бейдж «демо-режим»).
5. Визуал: cool limestone + deep teal + brass; display Cormorant, body Manrope.

## Состояния ошибок

- Ошибка `/api/route` → toast + возврат на последний шаг квиза.
- Ошибка `/api/ask` → текст в sheet, маршрут не ломается.
