# Чеклист дня IT-продлёнки (3 октября)

## До выхода из дома

- [ ] Ноутбук + зарядка + пауэрбанк
- [ ] Телефон для демо (и второй, если есть)
- [ ] Репозиторий `pushkin-curator` запушен / на флешке / в облаке
- [ ] `.env.local` шаблон готов (ключи получите на месте — не коммитить)
- [ ] Прочитаны `docs/DEMO.md` и `docs/UX.md`

## Старт (первые 40 минут)

- [ ] Собрать команду, назвать продукт («Мой куратор» или ваше имя)
- [ ] Распределить роли:
  - **Dev** — UI + API + деплой
  - **Design** — визуал, типографика, микроанимации
  - **Content** — факты в `artworks.json`, tone of voice
  - **Product** — питч, сценарий демо, тайминг
- [ ] `npm install && npm run dev` — показать кликабельный каркас
- [ ] Уточнить у организаторов: доступ к Yandex AI Studio / folder / API key

## К 11:00

- [ ] Все 6 экранов кликабельны на телефоне (локальный URL / туннель)
- [ ] Контент правит минимум 10 карточек под реальные залы (если дадут данные)

## К 14:00

- [ ] `YC_API_KEY` + `YC_FOLDER_ID` в `.env.local`
- [ ] Живая генерация через `/api/route`
- [ ] Ask-куратор через `/api/ask`
- [ ] Fallback проверен: выключить ключ → демо всё равно работает

## К 16:00 — polish

- [ ] HTTPS-деплой (Vercel / Yandex Cloud / что дадут)
- [ ] PWA: «Добавить на экран Домой»
- [ ] Share-ссылка открывается на другом телефоне
- [ ] 2–3 анимации на месте (переход карточек, generating, finish-открытка)
- [ ] Прогнать демо-скрипт 90 сек дважды

## Env

```bash
cp .env.example .env.local
# YC_API_KEY=...
# YC_FOLDER_ID=...
npm run dev
```

## Деплой (быстрый)

```bash
npm run build && npm start
# или: vercel --prod
```

Туннель на день, если деплой тормозит: `npx localtunnel --port 5173` / cloudflared / ngrok.

## Fallback-правило

Демо **никогда** не ломается из-за ИИ: при любой ошибке модели отдаём шаблонный маршрут из `buildFallbackRoute`.
