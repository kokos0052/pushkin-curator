# Питч и демо-скрипт

## Питч — 30 секунд

«Люди теряются в Пушкинском между шедеврами. Мы за четыре коротких ответа собираем маршрут под время и настроение и ведём как личный куратор — с короткими историями и ответами по ходу. Это не аудиогид для всех, а маршрут для тебя. Открывается на любом смартфоне, добавляется на домашний экран.»

## Демо на телефоне — 90 секунд

1. **0:00–0:10 — Landing**  
   Показать бренд «Мой куратор», одну фразу, нажать «Собрать маршрут».

2. **0:10–0:30 — Quiz**  
   Тапнуть: 60 мин → Открытие → Импрессионизм → Один.  
   Комментарий: «Четыре тапа, без анкеты.»

3. **0:30–0:45 — Generating → Overview**  
   Дождаться названия маршрута.  
   Комментарий: «ИИ собирает порядок и истории из каталога музея, не из интернета.»  
   Если виден «демо-режим» — сказать: «Есть надёжный fallback без ключа.»

4. **0:45–1:10 — Stop ×2**  
   Открыть первую остановку, прочитать «Почему тебе».  
   «Спросить куратора» → пресет «Что заметить первым?» → показать ответ.  
   Перейти на вторую остановку.

5. **1:10–1:30 — Finish / Share**  
   Завершить маршрут, показать открытку, нажать «Поделиться» (или скопировать ссылку).  
   Закрыть: «К концу дня — полноценный веб-сервис в портфолио.»

## Вопросы, которые могут задать эксперты

- **Чем отличаетесь от аудиогида?** — Персонализация + контекст «почему тебе», а не общий трек.
- **Откуда данные?** — Курируемый каталог 30 произведений + генерация нарратива.
- **Что если ИИ ошибётся?** — Валидация JSON, только id из каталога, fallback-маршрут.
- **Что дальше?** — Больше залов, схема этажей, голос, сохранение «мои маршруты».
